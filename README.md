# Lakshya BPSC starter app

AI-assisted mobile-first PWA. Includes 30 History and 30 Science & Technology MCQs, clickable answers, +1/-1/3/0 scoring, explanations, saved attempts, daily score chart, accuracy and test history.

## Android installation
1. Publish these files to an HTTPS static host (GitHub Pages, Netlify or Cloudflare Pages).
2. Open the hosted URL in Chrome on Android.
3. Chrome menu ⋮ → Install app / Add to Home screen.
4. Open Lakshya from your home screen. After the first load, the app shell is cached for offline use.

This ZIP is a PWA source package, not a native APK. A PWA needs HTTPS for service-worker installation.

## Current limits
Profile and progress are stored locally in this browser/device. No secure cloud account, multi-device sync, backend, subscription payments or admin question CMS is connected. History and Science & Technology are the first content packs; Polity, Geography, Economy and Bihar Special are planned next. Review factual details against standard texts and official sources.
