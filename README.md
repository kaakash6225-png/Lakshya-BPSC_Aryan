# Lakshya BPSC — Version 2.0 update

## What's new
- Full BPSC Prelims syllabus map across History, Polity, Geography, Economy, Bihar Special, General Science, Science & Technology, Environment, Current Affairs and Mental Ability.
- Mains workspace for General Hindi, Essay, GS Paper I and GS Paper II, with local answer-draft saving.
- Trusted-source library linking to BPSC official syllabus, question booklets and notices; NCERT/ePathshala; Bihar Government; Bihar Finance Department; Union Budget and Economic Survey.
- Existing 60 History and Science & Technology questions retained.
- Existing local profile and test history are preserved using the same `localStorage` key.
- Updated service worker cache version and navigation refresh strategy.

## Content integrity
- The existing History and Science & Technology question sets are explicitly labelled **AI-assisted practice — not verified PYQs**.
- No question is labelled as a Previous Year Question unless it has been checked against an original BPSC question booklet.
- New subject areas are mapped in the syllabus, but their question banks remain disabled until source and answer verification is completed.
- The Mains workspace is a personal writing notebook, not an official evaluation or marking engine.
- Always confirm current syllabus, paper structure, marks and qualifying rules from the latest BPSC notification.

## Deploy
Upload the contents of this folder to the root of the existing GitHub Pages repository, replacing the old files. Keep the repository and Pages settings unchanged.

## Local data
The app retains the existing `lakshya-bpsc-v1` browser storage key for continuity. Progress and drafts remain on this browser/device; there is no cloud account or multi-device sync.
